🛡️ Блок 1: Защита от копирования (Текст и Изображения)
Эти задачи научат вас перехватывать базовые действия пользователя и манипулировать буфером обмена.

Задача 1: Блокировка контекстного меню (Правый клик)

Задание: Запретите открытие контекстного меню на всей странице или на конкретном изображении. При попытке клика правой кнопкой мыши выводите alert("Копирование запрещено!").

Подсказка: Используйте событие contextmenu и метод event.preventDefault().

Задача 2: Запрет выделения текста

Задание: Сделайте так, чтобы пользователь не мог выделить текст мышкой на странице.

Подсказка: Есть два пути. Первый — CSS-свойство user-select: none;. Второй — JavaScript-событие selectstart с preventDefault().

Задача 3: Защита изображения «пустышкой» (Overlay)

Задание: Наложите поверх картинки прозрачный div. При попытке сохранить картинку через ПКМ пользователь будет кликать по div, а не по изображению. При этом сама картинка должна быть видна.

Подсказка: Используйте абсолютное позиционирование (position: absolute), z-index и прозрачный фон.

Задача 4: Защита через <canvas>

Задание: Загрузите изображение в элемент <canvas> с помощью JavaScript (drawImage). Прямо со страницы сохранить его через ПКМ уже не получится (браузер не предложит "Сохранить картинку").

Дополнительно: Запретите ПКМ именно на этом canvas.

Задача 5: Подмена текста при копировании (Ctrl+C)

Задание: Сделайте так, чтобы при копировании текста с вашей страницы (через Ctrl+C или меню) в буфер обмена попадал не только сам текст, но и ссылка на ваш сайт (например: "Статья скопирована с сайта site.com").

Подсказка: Используйте событие copy на document. Получите выделенный текст через window.getSelection().toString(), измените его и запишите в буфер через event.clipboardData.setData('text/plain', newText).

🎬 Блок 2: Защита от скачивания видео
Здесь мы будем имитировать поведение крупных стриминговых платформ. Ни одна из этих задач не дает 100% гарантии (видео можно записать через OBS), но они усложняют жизнь обычному пользователю.

Задача 1: Отключение стандартных элементов управления

Задание: Создайте тег <video>. Сделайте так, чтобы при клике на видео (или через ПКМ) у пользователя не было кнопки "Скачать" (которая иногда появляется в Chrome).

Подсказка: Используйте атрибут controlsList="nodownload". Также отключите контекстное меню через oncontextmenu="return false;".

Задача 2: Запрет «Картинка в картинке» (PiP)

Задание: Запретите пользователю включать режим «Картинка в картинке» (когда видео отрывается от вкладки и висит поверх всех окон).

Подсказка: Используйте атрибут disablePictureInPicture в теге <video>.

Задача 3: Скрытие реального URL видео через Blob

Задание: Обычно в исходном коде можно найти прямую ссылку на .mp4 файл. Сделайте так, чтобы при просмотре исходного кода страницы ссылки на видео не было.

Подсказка: Загрузите видеофайл через fetch() в формате Blob (двоичный объект), создайте ссылку через URL.createObjectURL(blob) и подставьте её в src тега <video>. Удалите исходную ссылку из HTML.

Задача 4: Стриминг через HLS (Продвинутый уровень)

Задание: Разбейте видео на короткие кусочки (chunks) и передавайте их по протоколу HLS (как это делают YouTube или Netflix). Напрямую скачать такое видео одной кнопкой невозможно.

Подсказка: Для этого в реальной разработке используется библиотека hls.js. Вам не нужно кодировать видео вручную, просто попробуйте подключить hls.js к тестовому потоку (m3u8) и изучить, как формируются сетевые запросы во вкладке Network.

⬆️ Блок 3: Кнопка «Наверх» (Back to Top)
Это классическая задача на работу со скроллом и событиями окна.

Задача 1: Базовая кнопка

Задание: Сделайте кнопку, которая появляется, когда пользователь прокручивает страницу вниз на 300 пикселей, и скрывается, когда он возвращается наверх. При клике страница плавно прокручивается в начало.

Подсказка: Отслеживайте событие window.onscroll. Проверяйте window.scrollY. Для прокрутки используйте window.scrollTo({ top: 0, behavior: 'smooth' }).

Задача 2: Плавное появление (Анимация)

Задание: Доработайте Задачу 1. Кнопка не должна просто резко появляться (display: block). Она должна плавно исчезать и появляться (например, меняя opacity и visibility).

Подсказка: Используйте CSS-переходы (transition) и переключайте классы через classList.add() / classList.remove().

Задача 3: Кнопка с индикатором прогресса

Задание: Сделайте кнопку «Наверх» в виде круга. Вокруг нее должна рисоваться цветная линия (прогресс-бар), которая заполняется по мере прокрутки страницы. Когда вы в самом низу — круг замкнут.

Подсказка: Вам понадобится SVG-элемент <circle> с атрибутом stroke-dasharray. В зависимости от процента прокрутки (window.scrollY / (document.body.scrollHeight - window.innerHeight)) меняйте stroke-dashoffset.

Задача 4: Использование Intersection Observer (Современный подход)

Задание: Перепишите логику появления кнопки (из Задачи 1) без использования события scroll. Вместо этого используйте IntersectionObserver.

Подсказка: Разместите в самом начале страницы невидимый элемент <div id="top-sentinel"></div>. Следите за ним через Observer. Если он выходит из зоны видимости (уходит вверх) — показывайте кнопку. Это работает намного производительнее, чем постоянная проверка scroll.

Задача 5: Оптимизация (Throttling / Debouncing)

Задание: Событие scroll срабатывает сотни раз в секунду при прокрутке, что нагружает процессор. Напишите функцию-обертку, которая будет вызывать ваш код не чаще, чем раз в 100 миллисекунд.

Подсказка: Это называется «троттлинг» (throttling). Используйте setTimeout и флаг состояния для ограничения частоты вызовов.

Совет по проверке: Для задач Блока 1 и 2 обязательно открывайте вкладку Network в DevTools (F12) и смотрите, какие запросы уходят на сервер. Для Блока 3 используйте вкладку Elements, чтобы в реальном времени видеть, как меняются классы и CSS-свойства вашей кнопки при скролле. Удачи в практике!
